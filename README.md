# ToolsManager

コマンドや環境構築を必要とするツールの簡略化

## 概要

ToolsManagerは、コマンドライン操作や複雑な環境構築が必要なツールを、Web上から直感的に操作することを目的としたWebアプリケーションです。

コマンドライン操作や環境構築の知識がない方にとって利用しやすいだけでなく、有識者の作業効率化目的で活用できる汎用性の高いUIを提供することで、ツールの利用ハードルを下げることを目的としています。

現在はFFmpegを利用した動画・音声の変換機能の実装を中心に開発を進めています。
今後、様々な機能を実装していく予定です。

## 開発目的

普段開発や創作活動を行う中で、コマンドライン操作や環境構築が求められるツールをいくつか利用してきました。

自分のやりたいことではない分野の知識を求められることもあり、調べながら試行錯誤するうちに、作業自体のモチベーションがなくなることも珍しくありませんでした。

そこで、ツール利用の敷居を少しでも下げるべく、直感的に操作可能なUIで、ツールの実行や環境構築のサポートを行うことのできるサービスを作ろうと思い至りました。

単なる補助サービスではなく、セキュリティや保守、運用、可読性などWebサービスとして基本的なことを意識し、開発を進めることを目標としています。

## 主な機能

### アカウント機能

- 新規アカウント登録
- ログイン
- Spring Securityによる認証
- パスワードのハッシュ化保存

基本的なアカウントサービスです。

### FFmpeg Converter

- 動画・音声の形式変換
- 音声抽出、静止画切り抜きなど

FFmpegをクライアント側でダウンロードすることなく、Web UIとして実行するサービスです。

### 初心者向けモード

FFmpeg Converterや今後実装予定の機能に共通する機能の一つで、専門用語や前提知識を必要とせず、質問に答えるだけで利用できる機能です。

主に何を調べたらいいのかわからない、細かい操作の理解が難しい、といった方を対象としています。

### 開発者向けモード

FFmpeg Converterや今後実装予定の機能に共通する機能の一つで、詳細設定やオプションなどを効率的に指定できる機能です。

主に開発者や有識者で、毎回の作業がめんどくさい、効率化したい、といった方を対象としています

### 実装予定機能

- アカウントページ
- ログイン時の固有機能 (ツールの使用履歴等)

## 設計方針

本プロジェクトは

「ツールを利用したい人」と
「ツールの詳細を理解している人」

の両方に対応するため

初心者向けUI
開発者向けUI

を分離しています。

また、フロントエンドとバックエンドをHTTP通信で分離し、データはJSON形式でやり取りする構成を採用しています。

## 開発について

本プロジェクトでは、完成品を作るための手段としてではなく、設計・学習・レビューを支援する開発補助ツール、という認識で生成AIを利用しています。
具体的には設計・実装・デバッグを自身で行いながら、コードレビューや技術調査、設計検討の補助として生成AIを活用しています。

フロントエンドでは、こちらから基本となるレイアウトや要件を提示したうえで、レイアウトの整形や補完を依頼しています。その際は、生成されたコードの変更点を必ず確認し、自身で修正や改善を行えることを前提としています。

バックエンドでは、必要な技術調査や設計相談、Java・JavaScriptのコードレビューを中心に活用しています。実装に関する質問は行いますが、実装するコードは自分の手で書くことを前提としています。
