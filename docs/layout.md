# Layout

## Header

目的:
サービス名の紹介とアカウント機能への案内

配置要素:

- サービス名
- Home
- アカウントページ
- ログイン
- 新規登録

## Main Content

目的:
使用ツールの選択、実行

配置要素:

- FFmpeg Converterの紹介
- 実行オプションフォーム
- 出力結果の表示
- Git Setup Assistantの紹介
- コマンドオプションフォーム
- 出力したコマンドの表示

## Sidebar

目的:
各コンテンツへのナビゲーション

配置要素:

- FFmpeg Converter
- Git Setup Assistant
- その他ツール(随時追加)

## Footer

目的:
バージョン情報および関連情報の記載

配置要素:

- コピーライト
- このページのGitHub
- Version
